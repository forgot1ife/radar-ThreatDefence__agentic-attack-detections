# What Ares leaves behind

Ares ([dreadnode/ares](https://github.com/dreadnode/ares), created December 15, 2025, reviewed at `786b2987bfeb08284b93802c3f533c54738e1e48`, October 28, 2026; MIT; Rust, with Ansible, shell and Python helpers; 109 stars and 23 forks on November 26, 2026; not archived; tags `v0.1.0` to `v0.3.0`) is Dreadnode's "autonomous security operations agent". The red team mode runs seven LLM-driven worker roles (recon, credential_access, cracker, acl, privesc, lateral, coercion) under an LLM orchestrator and chains about 64 Active Directory attack tools from recon to domain dominance. The blue team mode investigates the same attacks in Loki and Prometheus. File references are to the repository at `786b2987`. Ares is not on crates.io, PyPI, npm or Docker Hub. The docs and build templates name images under `ghcr.io/l50/` (for example `ghcr.io/l50/ares-orchestrator`, built from `github.com/l50/ares`); whether those images are public was not checked. There is no hosted service.

**Fragility** says what it takes to remove a signal: *code* means editing Ares, *config* means a value in `config/ares.yaml`, `.env` or an environment variable, *operator* means a choice made at run time, *code (prompt)* means the model decides, steered by a prompt template.

Ares ships its own detections for the attacks it runs: 58 LogQL templates over Windows events in `ares-core/src/detection/detections.yaml` (password spray, Kerberoasting, AS-REP roasting, DCSync, secretsdump, Shadow Credentials as event 5136 on `msDS-KeyCredentialLink`, ADCS ESC1, ESC4 and ESC8, RBCD and S4U, golden and silver tickets, SID history, MSSQL xp_cmdshell and linked servers, GPO scheduled tasks, and more), ten recipes in `ares-tools/src/blue/data/detection_recipes.yaml`, and `ares ops export-detection`, which writes a `detection_playbook.json` and `.md` from a finished operation (`ares-cli/src/detection/mod.rs`). The blue agents write their own alert rules into Grafana under folder `ares-security`, group `ares-detections` (`ares-tools/src/blue/grafana/rules.rs:13-14`). Those catch the techniques, whoever runs them. This folder does not copy them: it covers what identifies Ares itself.

The file `ares-tools/src/privesc/windows_payload.rs` (17,437 bytes, blob `b075f726`) was not read, by policy for payload code.

## Signals on the target side

Most of what a target sees is the stock tool Ares picked. These are the values Ares' own code puts on the wire or into the directory.

## Exposure

Ares has no web console and no API server, so there is no page title or favicon to search for. The only service with an Ares-specific banner is the NATS broker its Ansible role installs (`server_name: "ares-nats"`, in the NATS INFO banner on 4222 and in `/varz` on 8222), and it is bound to 127.0.0.1 by default. The optional benchmark replay stack publishes Grafana with anonymous Admin, Prometheus and Loki on every interface, but with stock pages and no Ares marker.
