# What 0security leaves behind

0security ([0sec-labs/0security](https://github.com/0sec-labs/0security), formerly `0sec-labs/0`, which GitHub redirects; repository created August 19, 2026; MIT or Apache-2.0, except `enterprise/`, which needs a license key in production; 1,624 stars and 223 forks on November 26, 2026; latest release `v0.45.0`, November 24, 2026; reviewed at `eec0d4c7`, November 25, 2026) is a TypeScript harness for "persistent AI security agents" that review code, keep a list of findings, fix them as pull requests and, on request, test live targets. It ships as one binary, `0security` with the alias `0`, a web console, a GitHub Action and a Docker image. The vendor is a Y Combinator company that sells an enterprise edition and a cloud service at 0.security. The repository also carries `0verse`, a separate binary-analysis tool that produces proof-of-vulnerability artifacts from compiled programs; it is out of scope here. File references are to the repository at `eec0d4c74e8bba71a158ff1f8309c4565786f764`.

**Fragility** says what it takes to remove a signal: *code* means editing 0security, *config* means an environment variable or setting, *operator* means a choice made at run time. *Code (prompt)* marks a string that is an example in a prompt, playbook or skill: removing it means editing 0security, but the model can also change it on any run, so treat it as likely, not certain.

## An exposed 0security console

A local console is bound to loopback and answers only requests whose `Host` is that loopback address, so it is reachable from outside only through a tunnel or a proxy that rewrites `Host`. The Docker image runs server mode on `0.0.0.0:48123` with an allow list of `localhost,127.0.0.1`, so a scanner that connects by IP address gets a 403 until the operator adds a host name.

## Signals in model traffic

Where model traffic is inspected, console requests carry a system prompt that starts `You are 0, an interactive security assistant. You work in the operator's folder` and includes `You are talking to a trusted operator on an authorized engagement.` (`packages/engine/src/console/turn-engine/prompt-and-runtime.ts:76-84`). ## What has been seen in the wild

- No vendor or CERT report of 0security used in an intrusion was found (searched November 26, 2026).
- No public detection rules for 0security were found.
- 0security is promoted to security and development teams and has a commercial enterprise edition and cloud service. A match on its traffic or files means someone ran it; whether that was authorized is the question to answer.

## What the code does not contain

No implant, C2 listener, webshell manager or persistence on a target. No hard-coded user agent on the agent's own HTTP requests to targets: they come from `curl`, Python or Nuclei. The live-target commands refuse public hosts unless the operator types the host name and always refuse link-local and metadata addresses. The Docker image does carry Active Directory and Azure attack tooling (Impacket, Certipy, BloodHound CE, AzureHound) that the agent can run with its shell; no command in the CLI drives those tools by itself at this commit.
