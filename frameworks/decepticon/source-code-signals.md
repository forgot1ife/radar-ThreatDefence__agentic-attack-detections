# What Decepticon leaves behind

Decepticon ([BitterSecurity/Decepticon](https://github.com/BitterSecurity/Decepticon), reviewed at `6b15092d`, November 20, 2026; repository created June 6, 2025; Apache-2.0; 6,716 stars and 1,306 forks on November 26, 2026; latest release `v2.2.2`, October 28, 2026) is an autonomous red team agent: a set of LangGraph agents (orchestrator, recon, exploit, post-exploit, AD, cloud, phishing, reverser and more) that run commands in a Kali sandbox and can start Sliver or Havoc C2, BloodHound CE and a reverse-engineering service on demand. It is installed with a Go launcher and runs as a Docker Compose stack. Its open web console was removed on November 11, 2026 (`02864fbd`, "remove OSS web dashboard in favor of the SaaS UI"); a hosted console is sold at app.decepticon.red. The Python packages `decepticon` and `decepticon-sdk` are on PyPI (2.2.2). File references are to the repository at `6b15092d` unless another commit is named; the console references are to `d26ddaa1`, the last commit before its removal.

**Fragility** says what it takes to remove a signal: *code* means editing Decepticon, *config* means a setting or environment variable, *operator* means a choice made at install or run time. *Code (prompt)* marks a string that is an instruction or example in a skill or prompt: removing it means editing Decepticon, but the model can also change it on any run, so treat it as likely, not certain.

## Signals on the target side

Most of what Decepticon sends to a target comes from the Kali tools in its sandbox (nmap, nuclei, sqlmap, ffuf and others, with whatever flags the model picks) and from curl_cffi browser impersonation. Its opsec skill tells the model to rotate current browser user agents. So the target side has few signals of its own.

## Corrections to the first version of this page

- `decepticon-roe/1` and `decepticon-http-sandbox/1` were listed as target-side signals. The first goes only to crt.sh, the second only to Decepticon's own sandbox daemon; both are host-side.
- `Decepticon/1.0` was listed as the model gateway user agent in general. It is set on one LiteLLM model entry (Vercel AI Gateway, Claude Haiku 4.5) only.
