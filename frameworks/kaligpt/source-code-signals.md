# What KaliGPT leaves behind

KaliGPT ([SudoHopeX/KaliGPT](https://github.com/SudoHopeX/KaliGPT), first commit August 4, 2025, reviewed at `b15b8d48367f9d2b9b3bd7edc40daa42445a1228`, November 25, 2026, on the default branch `hackerx`; latest tag `v1.3.6`; "SudoHopeX Non-Commercial Software License"; Python and shell; 820 stars and 152 forks on November 26, 2026; not archived) is a command-line AI agent for offensive security that calls itself **HackerX (KaliGPT v1.3)**. There is no PyPI package, no Docker image and no hosted service: it is installed from a `curl | bash` script into `/opt/KaliGPT`. Its web search goes through a companion project, [SudoHopeX/OpenSearchAPI](https://github.com/SudoHopeX/OpenSearchAPI), which the installer clones next to it; the OpenSearchAPI references below are to that repository at `02108abaa73f991b48bfd39daddd8af5838eae70` (read file by file, not cloned). Other file references are to KaliGPT at `b15b8d48`.

**Fragility** says what it takes to remove a signal: *code* means editing KaliGPT, *config* means a value in its settings, *operator* means a choice made at run time, *code (prompt)* means the model decides, steered by KaliGPT's system prompt.

## Exposure

KaliGPT has no web console. The only listener is the OpenSearchAPI search helper, which Flask binds to 127.0.0.1:5000 (`app.run(port=5000)`, no host argument), with no authentication. It is reachable from other hosts only if an operator changes the bind address or forwards the port; it would then be an open search proxy that drives chromium. Its `/` page has the title `OpenSearchAPI API | Docs` and `<h1 ...>OpenSearchAPI</h1>`; it has no favicon file (the page uses inline SVG), so there is no favicon hash. The same helper is also run on its own by people who do not use KaliGPT, so a hit on that title means OpenSearchAPI, not necessarily KaliGPT.
