# What Clearwing leaves behind

Clearwing ([Lazarus-AI-OSS/clearwing](https://github.com/Lazarus-AI-OSS/clearwing); the earlier name `Lazarus-AI/clearwing`, which the code and `pyproject.toml` still use, now redirects; MIT; repository created April 14, 2026; one release, `v1.0.0`; 1,091 stars and 162 forks on November 26, 2026; reviewed at `08fe47d2` (`08fe47d24d69b2f7352515f22b22d0f81be7ad15`), November 24, 2026) is a Python tool with two halves. One is a network pentest agent: a ReAct loop with 129 `@tool` functions under `clearwing/agent/tools/` (the README says 63 bound tools) that scans hosts, drives a Kali container, runs a headless browser, searches Exploit-DB, generates and signs payloads and can start an autonomous "operator" that answers its own approval prompts. The other is a source-code vulnerability hunter (`sourcehunt`) with sandboxed hunters, a campaign runner over many repositories, an N-day exploit pipeline and a disclosure workflow. Its README credits Eric Hartford of Lazarus AI and says it was inspired by Anthropic's Glasswing. File references are to the repository at `08fe47d2`.

**Fragility** says what it takes to remove a signal: *code* means editing Clearwing, *config* means an environment variable or setting, *operator* means a choice made at run time. *Code (prompt)* marks a string the system prompt asks for: removing it means editing Clearwing, but the model can also skip it on any run, so treat it as likely, not certain.
