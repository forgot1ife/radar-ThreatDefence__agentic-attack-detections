# Guardian Detection Rules and IOCs

Part of [Agentic Attack Detections](../../README.md). Shared indicators and feeds live at the repository root; the rules for behaviors that every agentic framework shows are in [`behaviors/`](../../behaviors).

**Guardian** ([zakirkun/guardian-cli](https://github.com/zakirkun/guardian-cli), reviewed at `51864a81`, June 28, 2026). AI pentest CLI in Python (Typer). A planner, a tool selector, an analyst and a reporter, each a model call through LangChain, run YAML workflows (25 shipped, including an autonomous mode) that start about 50 wrapped tools against a target: nmap, masscan, httpx, subfinder, amass, nuclei, ffuf, gobuster, sqlmap, wpscan, nikto, XSStrike, NetExec, kerbrute, Prowler, Trivy, garak and others. It writes a session checkpoint and Markdown, HTML, JSON or SARIF reports. Model providers: OpenAI (the default, `gpt-4o`), Anthropic, Google Gemini, OpenRouter, Requesty, Ollama, any OpenAI-compatible server and LiteLLM.

Guardian has no web console and no API server: it is a command-line tool and opens no listener, so there is nothing to find on the internet. On a target it shows up as one fixed user agent from its screenshot tool and one fixed prompt-injection request from its LLM fuzzer, followed by stock scanner traffic. The strongest signals are on the host that runs it. No vendor or CERT report of Guardian in a real intrusion was found on November 26, 2026.

Guardian's scans come from stock tools, so the cross-framework rules in [`behaviors/`](../../behaviors) carry most of the target-side detection: model API calls from servers and scanner traffic against your sites.

Indicators go in [`../../iocs/indicators.csv`](../../iocs/indicators.csv) with `framework` set to `guardian`.

## Limits

- Only two of Guardian's own requests reach a target: the screenshot tool (only when Playwright is installed and a workflow step uses it) and the prompt fuzzer's first payload. Everything else is a stock tool's traffic.
- The user agent, prompts, file names and headers are easy to change in a fork; the rules catch Guardian as published.
- Model-traffic rules need TLS inspection or an AI gateway. Most targets are HTTPS, so the user-agent rules see them only in web server logs or behind a TLS-inspecting proxy.
- A match means Guardian, not an attacker: it is published for authorized tests. Check who runs it and against what.
