# What NeuroSploit leaves behind

NeuroSploit ([JoasASantos/NeuroSploit](https://github.com/JoasASantos/NeuroSploit); repository created August 17, 2025; MIT; 1,569 stars and 372 forks on November 26, 2026; not archived; latest release `v4.4.2`, November 16, 2026; reviewed at `54d8e860` (`54d8e86039c0821017ced8c79e4fb9b55a9c4614`), November 24, 2026, where the workspace version is `4.4.3`) is a Rust command-line harness (`neurosploit`) with a Node.js web console. It runs reconnaissance, picks specialist agents from a library of 493 Markdown prompts (`agents_md/`), lets them exploit a target in parallel through model CLIs or model APIs, replays every claim over the wire, has a second model vote on it, chains findings and writes a report. It has its own out-of-band (OOB) listener, an intercepting proxy, an ngrok tunnel, and an opt-in C2 and web shell manager with bash, Python, PowerShell and PHP beacons and persistence commands. Languages by size: Rust, JavaScript, CSS, HTML, Shell. There is no Dockerfile, no published container image and no PyPI package; the npm package named in `mcp/package.json` (`@neurosploit/mcp-server`) is not on the npm registry (HTTP 404 on November 26, 2026). The project home page is `neurosploitai.github.io`.

File references are to the repository at `54d8e860`. `harness/` means `neurosploit-rs/crates/harness/`, `app/` means `neurosploit-rs/app/`.

**Fragility** says what it takes to remove a signal: *code* means editing NeuroSploit, *config* means an environment variable, flag or setting, *operator* means a choice made at run time. *Code (prompt)* marks a string the code hands to the model as an instruction or example: removing it means editing NeuroSploit, but the model may also change it on any run, so treat it as likely, not certain.
