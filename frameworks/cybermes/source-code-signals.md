# What Cybermes leaves behind

Cybermes ([Zyrexnn/Cybermes](https://github.com/Zyrexnn/Cybermes), first commit August 19, 2026, reviewed at `149b9a66752244bbb78926dcdc94dfc5b647ed80`, November 16, 2026, release v3.5.1 plus documentation commits; Apache-2.0; Go, Python, JavaScript and shell; 1,071 stars and 180 forks on November 26, 2026; not archived) calls itself an "Autonomous Offensive Security, Bug Bounty & Red Teaming Agent Framework". It is a layer on top of [Hermes Agent](../hermes): wrapper scripts, a Hermes persona and configuration, about 220 skills, vendored knowledge (HackTricks, PayloadsAllTheThings, Claude-BugHunter, hack-skills, strix-skills), vendored copies of sqlmap and Strix, and a Go MCP server, `cybermes-mcp`, published on npm (`cybermes-mcp`, 3.0.0 on August 25, 2026 to 3.5.1). Its Docker image is `ghcr.io/zyrexnn/cybermes`. The Python project name `cybermes` in `pyproject.toml` is not on PyPI. There is no hosted service. File references are to the repository at `149b9a66`.

This page lists only what Cybermes adds. For Hermes itself (process, home folder, dashboard, Telegram gateway), see [What Hermes leaves behind](../hermes/source-code-signals.md).

**Fragility** says what it takes to remove a signal: *code* means editing Cybermes, *config* means a value in its settings, *operator* means a choice made at run time, *code (prompt)* means the model decides, steered by Cybermes' prompts.

## What has been seen in the wild

No vendor or CERT report of Cybermes in an intrusion was found on November 26, 2026; it has trade-press coverage as a new tool. The Hermes cases (Unit 42, Hunt.io, Gambit, ThreatDown) did not name Cybermes.

## What the code does not contain

No implant, C2 or exploit code of its own. The vendored sqlmap in `tools/sqlmap/` ships sqlmap's own stagers, backdoors and UDF libraries (not read for this review). No listener: the only server is `cybermes-mcp` over stdio. The `examples/mock_vulnerable_app.py` lab target is local test code.
