# What Nebula leaves behind

Nebula ([BerylliumSec/nebula](https://github.com/BerylliumSec/nebula), by Beryllium Security; repository created September 30, 2023; BSD-2-Clause; Python, TypeScript, Rust and Swift; 1,168 stars and 182 forks on November 26, 2026; not archived; 26 releases on GitHub from `nebula-v3.0.0-alpha.5` (July 22, 2026) to `nebula-v3.0.46` (November 9, 2026), with `Nebula-<version>-linux-x86_64.deb`, an AppImage and a `nebula_client` wheel; reviewed at `409bf4f9`, November 25, 2026, the latest commit, `NEBULA3_VERSION` `3.0.0-beta.3`) is an operator workstation for security testing. A Python core (`nebula-core`, FastAPI on uvicorn) keeps projects, runs agents, missions and a supervising agent called Butler against model APIs or the Codex, Claude and Grok command-line harnesses, runs commands in a Kali container or on the host, drives a Playwright Chromium through a mitmproxy interception proxy with intercept and Repeater, and writes findings and reports. A Tauri desktop app (`nebula-ui`), a browser workspace, an iOS shell and a terminal client (`nebula-chat`) connect to it. Nebula 1 and 2 were a different command-line tool, published as `berylliumsec/nebula` on Docker Hub (last updated April 12, 2025) and `nebula-ai` on PyPI (last release `2.0.1b2`); `docs/MIGRATING-2-TO-3.md` calls Nebula 2 discontinued. File references are to the repository at `409bf4f9`.

**Fragility** says what it takes to remove a signal: *code* means editing Nebula, *config* means a setting or environment variable, *operator* means a choice made at run time. *Code (prompt)* marks behaviour the system prompt asks for: removing it means editing the prompt, but the model can also ignore it on any run.

## What the code does not contain

No implant, C2 server, persistence or exploit payloads of its own, and no telemetry. Attacks run through the stock Kali tools, the browser and whatever the model writes. The repository's binary files are images, fonts and screenshots; no executable is committed (the `ui/src-tauri/binaries/` and `resources/` folders hold only `.gitignore`).
