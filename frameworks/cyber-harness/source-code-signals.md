# What cyber-harness leaves behind

cyber-harness ([chainreactors/cyber-harness](https://github.com/chainreactors/cyber-harness), formerly `chainreactors/aiscan`, which now redirects; repository created May 7, 2026, first tag `v0.0.1` on May 9, 2026; AGPL-3.0; 433 stars and 76 forks on November 26, 2026; reviewed at `02ac8ecf` (`02ac8ecfa6435610cbe7ee2f3e4deeb5481702c5`), November 25, 2026, two commits after `v1.0.0-rc10`) is a Go agent harness from the chainreactors group. It ships three binaries: `cyber-scan`, an LLM agent that drives the group's own scanners (gogo port scanning, spray web probing, zombie password guessing, neutron templates, katana crawling), a headless browser, a curl clone and any shell command; `cyber-audit`, a source-code and binary audit agent; and `cyber-harness`, a Web Hub that scan and audit nodes connect to. The system prompt calls it "a Cyber Harness for model companies to run benchmarks in cybersecurity scenarios". No Docker image, PyPI or npm package was found; releases are zip archives on GitHub. File references are to the repository at `02ac8ecf` unless a tag is named.

**Fragility** says what it takes to remove a signal: *code* means editing cyber-harness, *config* means a flag, environment variable or setting, *operator* means a choice made at run time. *Code (prompt)* marks a string that is an example in a prompt or skill: removing it means editing cyber-harness, but the model can also change it on any run.

**Names over time.** Until `v1.0.0-rc3` (September 9, 2026) the project was AIScan: binary `aiscan`, page title `AIScan`, user agent `aiscan`, data folder `.aiscan`. The rename to `cyber` landed on September 15, 2026 (commit `3a79aee`); `v1.0.0-rc4` to `rc9` still ship the binaries `aiscan` and `aiscan-full` with the new strings (`.goreleaser.yml:31,51` at `v1.0.0-rc9`), and `v1.0.0-rc10` (November 14, 2026) ships `cyber-scan`, `cyber-harness` and `cyber-audit`. The older strings are listed where they differ, with the tag `v0.4.0` (`9c5037a0`, August 3, 2026).

## Limits

- Most of the attack traffic comes from the chainreactors scanners and from shell tools the model starts; their request shapes are set in libraries this review did not read. The strings above are the ones in this repository.
- The two exact user agents appear only in two paths: the basic-auth check of the scan pipeline (after a `401`) and the `fetch` tool.
- A match means cyber-harness, not an attacker: it is published for authorized testing and benchmarks. Check who ran it and whether the test was agreed.
